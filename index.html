01 / ABOUT

I make on-chain claims verifiable, not just believable.

Most of my recent work sits at the boundary where an autonomous agent meets real money: warden, a self-hosted trading agent for BNB Smart Chain where every cap the agent operates under — per-trade, daily, drawdown, key expiry — is enforced by the account contract itself, not by application code that a bug or a prompt-injected message could talk around. It's a port and re-architecture of an upstream project; my own build is the PancakeSwap v3 venue layer, the TWAP pricing guards, and the on-chain breaker contracts that make the safety claims true on this chain.

Before that: Python and Django backends — APIs, webhook signature verification, database policy hardening, the layer where a quiet bug becomes a very loud incident. That instinct carried over directly into how I think about on-chain systems.
